# JobTrackr User Stories

1. As a user, I can register with email and password, so that my data is private.
2. As a user, I can log in with my credentials, so that I can securely access my saved applications and resumes.
3. As a user, I can add a job by pasting its description, so that I can track the position details in my dashboard.
4. As a user, I can list jobs with filtering and search options, so that I can quickly locate specific target roles.
5. As a user, I can update application status, so that I can track my real-time progress through the hiring pipeline.
6. As a user, I can view status history for an application, so that I can see the full timeline of my interview process.
7. As a user, I can upload a resume in PDF format, so that my skills and qualifications can be parsed by the system.
8. As a user, I can match resume to a job, so that I can evaluate how well my qualifications fit the position.
9. As a user, I can see missing skills for a job posting, so that I know what qualifications I need to acquire or highlight.
10. As a user, I can view dashboard analytics, so that I can analyze my application volume, response rates, and stage funnel.
11. As a user, I can set email follow-up reminders, so that I don't forget to follow up with recruiters after interviews.
12. As a user, I can view a weak spots summary across all jobs, so that I can identify the most common skills I am missing across all my target roles.
